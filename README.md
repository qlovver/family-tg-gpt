# family-tg-gpt

Приватный Telegram-бот с ИИ для двух человек на Cloudflare Workers (бесплатный тариф).
Модель: `claude-opus-5-5` через [Tooken Club](https://tooken.club) в формате Claude Messages API.

## Структура

| Файл | Что внутри |
|---|---|
| `worker.js` | точка входа Worker (только реэкспорт) |
| `src/bot.js` | Telegram webhook, команды, доступ, история, повторы, страница настройки |
| `src/model.js` | запросы к Tooken Club (`/v1/messages`, запасные форматы), ошибки, таймауты |
| `src/format.js` | Markdown + LaTeX → Telegram HTML, безопасное разбиение длинных ответов |
| `test/` | тесты с mock API: `node --test test/*.test.js` (Node 20+, без зависимостей) |
| `wrangler.jsonc` | конфигурация Worker, KV binding `HISTORY`, `keep_vars` |

## Настройки в Cloudflare

Secrets (Workers → family-tg-gpt → Settings → Variables and Secrets):

| Имя | Тип | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Secret | токен от @BotFather |
| `TOOKEN_API_KEY` | Secret | ключ `tc_live_…` |
| `WEBHOOK_SECRET` | Secret | проверка, что запрос пришёл от Telegram (латиница/цифры/`_-`, до 256 символов) |
| `SETUP_KEY` | Secret | пароль страницы `/setup` |
| `ALLOWED_USER_IDS` | Text или Secret | два ID через запятую: `123456789,987654321` |

Необязательные переменные (`TELEGRAM_API_URL` — только для локальных тестов): `MODEL` (по умолчанию `claude-opus-5-5`), `API_FORMAT` (`messages` / `chat` / `responses`),
`MODEL_STREAM` (`1` — потоковый ответ), `MAX_OUTPUT_TOKENS` (по умолчанию 4000), `TOOKEN_BASE_URL`.

KV binding `HISTORY` прописан в `wrangler.jsonc` (namespace `kv-get-started`), поэтому деплой из GitHub его больше не удаляет.
`keep_vars: true` сохраняет текстовые переменные из панели при деплое.

## Подключение webhook (с iPhone)

1. Открой `https://family-tg-gpt.qlovver.workers.dev/setup`.
2. Введи `SETUP_KEY` в поле (ключ больше не передаётся в адресной строке).
3. Оставь галочку «Подключить webhook», при желании отметь «Проверить модель» (один запрос на ~20 токенов).
4. Нажми «Выполнить». На странице будет: имя бота, состояние webhook и последняя ошибка Telegram,
   какой endpoint ответил и какое имя модели вернул Tooken.

Быстрая проверка конфигурации без пароля: `https://family-tg-gpt.qlovver.workers.dev/` (только да/нет, без значений).

## Команды бота

`/start`, `/help` — справка · `/id` — свой Telegram ID (доступно всем) · `/reset` — очистить свою историю и забыть файл ·
`/retry` — повторить последний неудачный запрос · `/word` — прислать последний ответ файлом Word (без запроса к модели).

## Файлы

**Читает:** .docx, .xlsx/.xlsm, .pptx (текст, таблицы, ячейки с формулами, слайды и заметки), .pdf (передаётся модели
как документ — работает, если Tooken пропускает PDF), текст и код (.txt, .csv, .md, .json, .py, …), картинки.
Не читает: старые .doc/.xls/.ppt, .odt, HEIC, архивы — бот попросит пересохранить. Лимиты: файл до 20 МБ (ограничение
Telegram), PDF до 10 МБ, из документа берётся до ~120 000 символов. Присланный файл хранится в KV 6 часов
(`lastfile:<id>`), чтобы можно было задавать вопросы по нему; `/reset` его удаляет.

**Создаёт:** Word, Excel (с формулами, несколько листов), PowerPoint (титульный слайд + слайды с пунктами).
Модель возвращает блок `<file type="docx|xlsx|pptx" name="…">Markdown</file>`, Worker собирает файл и отправляет
через `sendDocument`. PDF не создаётся: в Worker нет нормального способа собрать PDF с русскими шрифтами.

**CPU.** На бесплатном тарифе у Worker ~10 мс процессорного времени на запрос. Обычные файлы укладываются,
очень большие таблицы (тысячи строк) и тяжёлые PDF могут превысить лимит (ошибка 1102 в логах) — тогда поможет
Workers Paid ($5/мес, до 30 с CPU).

## Как устроено

- **Доступ.** Отвечает только ID из `ALLOWED_USER_IDS`. Посторонние получают отказ, модель не вызывается, KV не трогается.
- **История.** Ключ `history:<telegram_id>`, ID берётся из подписанного Telegram запроса, а не из текста — чужую историю
  запросить нельзя. Хранится до 12 сообщений и не больше ~20 000 символов, фото в KV не сохраняются.
- **Фото.** Берётся размер до 1600 px (дешевле и быстрее, Claude всё равно уменьшает большие изображения).
  Ответ (reply) на старое фото повторно отправляет это фото модели.
- **Повторы.** Повторная доставка того же update не вызывает модель второй раз. При ошибке модели пользователь получает
  понятное сообщение, запрос сохраняется для `/retry`. Если не удалось отправить готовый ответ, Telegram повторит
  доставку и ответ будет отправлен из KV без нового платного запроса.
- **Время.** Таймаут модели 85 с: Worker ждёт, пока Telegram держит соединение, и ещё до 30 с через `waitUntil`.
- **Квоты KV (free: 1000 записей/день).** 2 записи на одно сообщение.

## Приватность

Сообщения проходят через Cloudflare (хранение истории), Tooken Club и поставщика модели. Технически они могут обрабатывать
и хранить данные. Бот разделяет переписки между двумя пользователями, но не даёт абсолютной конфиденциальности.
